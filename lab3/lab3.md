# Lab 3: Neural Signal Processing & Decoding

This lab will give you hands-on experience analyzing electrophysiology data and its relationship with environmental/behavioral variables. We will be analyzing data collected by Prof. Orsborn. The data includes extracellular recordings from the motor cortex of a rhesus macaque monkey (macaca mulatta) while he performed an arm movement task. 

## Setup

Activate the Conda environment and install Lab 3's dependencies:

```bash
conda activate ee194-21
cd lab3
pip install -e .
```
